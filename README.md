# EasyDoMix

인터넷 권한 없는 안드로이드 음성 · 영상 믹싱 · 편집 앱. 여러 영상 · 오디오 트랙을 타임라인에서 자르고 겹치고 섞어 mp4 · m4a · wav로 내보내며, 데이터는 기기 밖으로 나가지 않음.

## 기능

| 영역 | 내용 |
|---|---|
| 프로젝트 | 화면 비율(16:9 · 9:16 · 1:1), 이름 변경 · 복제 · 삭제, 자동 저장, 앱 안 백업 · 복원 |
| 타임라인 | 영상 트랙(위가 앞 레이어) · 오디오 트랙 여러 개 · 자막 트랙, 확대 · 축소, 스냅, 실행 취소 · 다시 실행 |
| 클립 | 영상 · 오디오 · 이미지 추가(사진 선택기 · 파일), 끌어 이동 · 트랙 간 이동, 양 끝 트림, 분할, 삭제, 복제, 속도 0.25~4배 |
| 믹싱 | 트랙 볼륨 · 팬 · 음소거 · 솔로, 클립 볼륨 · 팬 · 페이드 인/아웃, 볼륨 키프레임, 3밴드 EQ, 노멀라이즈, 마스터 볼륨, 레벨 미터, 영상 원본 오디오 분리 |
| 영상 | 위 트랙 오버레이(PIP 위치 · 크기 · 불투명도), 크로스페이드 · 디졸브 전환, 밝기 · 대비 · 채도 |
| 자막 | 텍스트 · 시간 · 위치 · 크기 · 색 · 외곽선, SRT 가져오기 · 내보내기, 영상에 입히기 선택 |
| 내보내기 | mp4(H.264 · AAC, 480p · 720p · 1080p, 화질 3단계), 오디오만 m4a · wav, 진행률 · 취소, 백그라운드 진행 알림 |

원본 미디어는 앱으로 복사하지 않고 선택한 파일을 그대로 참조. 원본을 옮기거나 지우면 프로젝트에서 열 수 없음.

## 설치

[Releases](../../releases)에서 `EasyDoMix-<버전>.apk`를 받아 설치. Android 8.0 이상.

- 처음 설치 시 "출처를 알 수 없는 앱" 설치 허용 필요. Play 프로텍트가 검사 화면을 띄울 수 있음
- 업데이트는 새 APK를 같은 방식으로 덮어 설치. 프로젝트 · 설정 유지
- 앱 안 업데이트 알림 없음. Releases 페이지에서 직접 확인
- 서명 인증서 SHA-256: `c4068225381b81f1cc4d102bf7f6e5a601750506eb85f201520126b60ab96851`
  (`apksigner verify --print-certs EasyDoMix-<버전>.apk`로 확인)

## 개인정보

- **인터넷 권한 없음.** 수집 · 전송하는 데이터 없음. 계정 · 광고 · 사용 통계 · 오류 보고 없음
- 프로젝트는 기기 안에만 저장. 앱 삭제 시 함께 삭제 (Android 클라우드 백업도 끔)
- 내보낸 영상 · 오디오 · 자막 · 백업 파일은 사용자가 고른 위치에만 저장

## 알려진 제한

- 미리보기는 기기 성능에 맞춰 낮은 해상도로 합성. 영상 여러 개가 동시에 나오는 구간(전환 · 영상 PIP)은 기기에 따라 미리보기가 끊길 수 있음
- 백업에는 미디어 원본이 들어가지 않음
